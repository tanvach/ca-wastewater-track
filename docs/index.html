How is this calculated?
  1. Raw Concentration: We use the raw viral concentration (copies/L). Ideally, we would normalize by PMMoV (a harmless fecal plant virus) to account for dilution, but PMMoV data is unavailable in this specific dataset.
  2. Robust Smoothing: We use a two-step filter (Median then Rolling Average) to remove single-day outliers and show the true trend.
  3. % of Peak: levels are shown as a percentage of the highest smoothed value observed in the last 18 months.
(Note: CDPH updates data once daily.)
